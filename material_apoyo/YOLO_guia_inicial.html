1. Objetivo de la práctica

Al finalizar esta guía, el estudiante podrá ejecutar un modelo YOLO preentrenado, detectar objetos en distintos tipos de entrada y consultar la información que devuelve el modelo.

Reconocer

Identificar objetos como personas, vehículos, animales y elementos cotidianos.

2. ¿Qué es YOLO?

YOLO (You Only Look Once) es una familia de modelos de visión artificial utilizada para detectar objetos en imágenes y video. El modelo analiza una imagen y devuelve las detecciones encontradas en una sola ejecución de inferencia.

Imagen o fotograma→ Modelo YOLO→ Objetos detectados

¿Qué información produce una detección?

  • Clase: categoría asignada al objeto, por ejemplo, persona, perro o automóvil.
  • Confianza: puntuación entre 0 y 1 que expresa qué tan segura es la predicción del modelo. No debe interpretarse como una probabilidad perfectamente calibrada.
  • Bounding box: rectángulo que delimita la ubicación del objeto en la imagen.
Importante: un modelo preentrenado reconoce las clases incluidas en los datos con los que fue entrenado. No reconocerá automáticamente cualquier objeto personalizado.

3. Preparación del entorno

Se recomienda utilizar Python 3.9 o una versión compatible con la versión de Ultralytics instalada. Ejecuta los siguientes comandos en la terminal de tu entorno virtual o instalación de Python.

Instalar Ultralytics

pip install ultralytics

Instalar OpenCV (para mostrar video y cámara)

pip install opencv-python

Comprobar la instalación

from ultralytics import YOLO

print("Ultralytics se instaló correctamente")
Primera ejecución: al cargar por primera vez un archivo de pesos como yolo11n.pt, Ultralytics puede descargarlo automáticamente. Se necesita conexión a Internet para esa descarga inicial.

Sobre el modelo: en los ejemplos se utiliza yolo11n.pt, una variante pequeña de YOLO11 adecuada para comenzar y realizar pruebas. También puedes utilizar otro modelo compatible de la familia YOLO.

4. Cargar el modelo YOLO

El primer paso consiste en importar la clase YOLO y crear un objeto a partir del archivo de pesos. Ese objeto permitirá realizar las detecciones.

from ultralytics import YOLO

# Cargar un modelo preentrenado
modelo = YOLO("yolo11n.pt")

print("Modelo cargado correctamente")

Explicación

  • from ultralytics import YOLO importa la clase que permite utilizar los modelos.
  • YOLO("yolo11n.pt") carga los pesos del modelo. Si el archivo no está localmente, la biblioteca puede descargarlo.
  • modelo es el objeto que reutilizaremos en los siguientes ejemplos.
Consejo: carga el modelo una sola vez al inicio del programa. No es necesario volver a cargarlo dentro de cada iteración de la cámara o del video.

5. Ejemplo 1: detectar objetos en una imagen

Comenzaremos con una imagen almacenada en el equipo. Coloca una fotografía llamada objetos.jpg en la misma carpeta del programa. Procura que contenga objetos comunes y que estén bien iluminados.

from ultralytics import YOLO

modelo = YOLO("yolo11n.pt")

# Analizar la imagen
resultados = modelo("objetos.jpg")

# Mostrar la imagen con las detecciones
resultados[0].show()

Explicación paso a paso

  1. Se carga el modelo preentrenado.
  2. Se envía la ruta de la imagen al modelo.
  3. El modelo analiza la imagen y devuelve una lista de resultados.
  4. resultados[0].show() muestra la imagen con los rectángulos, nombres de clases y puntuaciones.

El método show() es útil para una primera comprobación visual. Más adelante accederemos directamente a los datos de las detecciones.

6. Ejemplo 2: detección en tiempo real con cámara web

Ahora utilizaremos la cámara del equipo. OpenCV obtiene los fotogramas y YOLO analiza cada uno para localizar objetos.

import cv2
from ultralytics import YOLO

modelo = YOLO("yolo11n.pt")

# Abrir la cámara predeterminada
camara = cv2.VideoCapture(0)

while True:
    ret, frame = camara.read()

    if not ret:
        print("No se pudo obtener imagen de la cámara")
        break

    # Ejecutar la detección
    resultados = modelo(frame)

    # Obtener el fotograma con las detecciones dibujadas
    frame_detectado = resultados[0].plot()

    cv2.imshow("Deteccion con YOLO", frame_detectado)

    # Salir al presionar la tecla Q
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

camara.release()
cv2.destroyAllWindows()

¿Qué hace cada parte?

  • cv2.VideoCapture(0) abre la cámara predeterminada. Si hay varias cámaras, puede ser necesario probar otro índice.
  • camara.read() obtiene un fotograma y devuelve si la lectura fue exitosa.
  • modelo(frame) analiza el fotograma actual.
  • resultados[0].plot() genera una imagen con las detecciones dibujadas.
  • cv2.imshow() presenta el resultado en una ventana.
  • cv2.waitKey(1) permite actualizar la ventana y detectar si se presionó Q.
Nota: el procesamiento puede ser más lento que la captura de la cámara. El rendimiento depende del equipo, la resolución, el modelo y si se utiliza CPU o GPU.

7. Ejemplo 3: analizar un archivo de video

La misma lógica puede utilizarse con un video previamente grabado. Guarda un archivo llamado video.mp4 en la carpeta del programa.

from ultralytics import YOLO

modelo = YOLO("yolo11n.pt")

resultados = modelo(
    source="video.mp4",
    show=True,
    save=True
)

print("Procesamiento finalizado")

Parámetros utilizados

ParámetroFunción
sourceIndica el archivo de video que se analizará.
show=TrueMuestra las detecciones durante el procesamiento.
save=TrueGuarda el resultado anotado en el directorio de salida de Ultralytics.

Este ejemplo permite comprobar que YOLO puede analizar secuencias de fotogramas, no solamente fotografías individuales.

8. Ejemplo 4: consultar los objetos detectados

Además de dibujar los resultados, podemos acceder a la información que devuelve YOLO. Esto será especialmente útil cuando queramos construir un sistema que tome decisiones según los objetos encontrados.

from ultralytics import YOLO

modelo = YOLO("yolo11n.pt")
resultados = modelo("objetos.jpg")

# Obtener el primer resultado
resultado = resultados[0]

# Recorrer las detecciones
for caja in resultado.boxes:
    clase_id = int(caja.cls[0])
    confianza = float(caja.conf[0])

    nombre = modelo.names[clase_id]

    print("Objeto:", nombre)
    print("Confianza:", round(confianza, 2))
    print("-------------------")

Comprender las variables

ExpresiónSignificado
resultado.boxesContiene las cajas delimitadoras detectadas.
caja.cls[0]Identificador numérico de la clase.
caja.conf[0]Puntuación de confianza de la detección.
modelo.names[clase_id]Nombre asociado al identificador de clase.
Idea clave: una detección no es solamente un rectángulo dibujado. También contiene datos que pueden utilizarse en conteos, clasificación de situaciones o automatización.

9. Ejercicio propuesto

Actividad práctica

Contador sencillo de personas

Modifica el ejemplo de cámara web para que el programa cuente cuántas personas aparecen en cada fotograma y muestre el total en la ventana.

Pistas

  1. Recorre las cajas de resultados[0].boxes.
  2. Obtén el identificador de clase con int(caja.cls[0]).
  3. Consulta el nombre de la clase usando modelo.names[clase_id].
  4. Si el nombre es "person", incrementa un contador.
  5. Utiliza cv2.putText() para mostrar el contador en el fotograma.
Ver una posible solución 
import cv2
from ultralytics import YOLO

modelo = YOLO("yolo11n.pt")
camara = cv2.VideoCapture(0)

while True:
    ret, frame = camara.read()
    if not ret:
        break

    resultados = modelo(frame)
    cantidad_personas = 0

    for caja in resultados[0].boxes:
        clase_id = int(caja.cls[0])
        nombre = modelo.names[clase_id]

        if nombre == "person":
            cantidad_personas += 1

    imagen = resultados[0].plot()

    cv2.putText(
        imagen,
        f"Personas: {cantidad_personas}",
        (20, 40),
        cv2.FONT_HERSHEY_SIMPLEX,
        1,
        (0, 255, 0),
        2
    )

    cv2.imshow("Contador de personas", imagen)

    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

camara.release()
cv2.destroyAllWindows()

Observación: el contador representa las personas detectadas en el fotograma actual. No es un conteo único de personas que han pasado por la cámara; para eso se necesitaría incorporar seguimiento de objetos.
