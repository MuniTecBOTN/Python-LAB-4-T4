Entrenamiento de modelos personalizados con YOLO

Aprender a etiquetar imágenes, entrenar modelos y reconocer objetos propios utilizando Python.

Objetivo general

Desarrollar modelos de detección de objetos utilizando imágenes etiquetadas por el estudiante, comprendiendo el proceso de preparación de datos, entrenamiento, evaluación y predicción.

Herramientas necesarias

  • Python 3.10 o superior.
  • Visual Studio Code o Google Colab.
  • Ultralytics YOLO.
  • Roboflow para etiquetar imágenes (opcional).

Instalación

pip install ultralytics

Para verificar la instalación: 

from ultralytics import YOLO

print("YOLO instalado correctamente")
Laboratorio 01

Entrenamiento con imágenes etiquetadas

En este laboratorio se utilizará un conjunto de imágenes previamente etiquetadas para entrenar un modelo capaz de reconocer dos tipos de objetos.

1. Planteamiento

Se desea crear un detector que reconozca dos objetos diferentes. Por ejemplo:

  • Botella.
  • Lata.

El modelo deberá aprender a identificar ambos objetos y dibujar un rectángulo alrededor de ellos.

2. Conseguir imágenes etiquetadas

Se puede utilizar Roboflow para crear un conjunto de datos:

  1. Crear una cuenta en Roboflow.
  2. Crear un proyecto de tipo Object Detection.
  3. Subir fotografías de botellas y latas.
  4. Etiquetar cada objeto dibujando un rectángulo.
  5. Asignar la clase correspondiente.
  6. Generar el conjunto de datos y exportarlo en formato YOLO.

Se recomienda utilizar al menos 50 imágenes por clase para comenzar con la práctica. Una mayor variedad de imágenes permitirá trabajar con mejores condiciones de entrenamiento.

Importante: las imágenes deben contener diferentes posiciones, distancias, fondos e iluminaciones. No es suficiente fotografiar repetidamente el mismo objeto desde una única posición.

3. Comprender las etiquetas YOLO

Cada imagen tiene un archivo de texto asociado con el mismo nombre. Por ejemplo: 

botella_01.jpg
botella_01.txt

El archivo TXT contiene una línea por cada objeto etiquetado. Cada línea tiene cinco valores: 

0 0.512 0.483 0.320 0.450
Valor Significado
0 Identificador de la clase.
0.512 Centro horizontal del rectángulo.
0.483 Centro vertical del rectángulo.
0.320 Ancho del rectángulo.
0.450 Alto del rectángulo.
Las coordenadas están normalizadas entre 0 y 1. El identificador de clase comienza en cero.

4. Estructura del conjunto de datos

Al exportar el proyecto, se debe obtener una estructura similar a la siguiente: 

dataset/
│
├── data.yaml
│
├── train/
│   ├── images/
│   └── labels/
│
├── valid/
│   ├── images/
│   └── labels/
│
└── test/
    ├── images/
    └── labels/

Cada carpeta tiene una finalidad:

  • train: imágenes utilizadas para aprender.
  • valid: imágenes para evaluar durante el entrenamiento.
  • test: imágenes reservadas para una evaluación final.

5. Archivo de configuración data.yaml

Este archivo indica dónde están las imágenes y cuáles son las clases que reconocerá el modelo. 

path: ./dataset

train: train/images
val: valid/images
test: test/images

names:
  0: botella
  1: lata

6. Código completo de entrenamiento

Crear un archivo llamado entrenamiento_01.py. 

# ==========================================
# LABORATORIO 01
# Entrenamiento de un modelo YOLO
# ==========================================

from ultralytics import YOLO

# 1. Cargar modelo preentrenado
model = YOLO("yolo26n.pt")

# 2. Entrenar el modelo
resultados = model.train(
    data="dataset/data.yaml",
    epochs=50,
    imgsz=640,
    batch=8,
    name="detector_botellas_latas"
)

print("Entrenamiento finalizado")

7. Explicación del código

Importación de YOLO 
from ultralytics import YOLO
Permite utilizar las herramientas de entrenamiento y detección de objetos de Ultralytics.
Cargar el modelo 
model = YOLO("yolo26n.pt")
Carga un modelo preentrenado. La variante n (nano) es una opción ligera para comenzar. El modelo ya conoce características visuales generales y podrá adaptarlas a las clases de nuestro conjunto de datos.
Entrenar el modelo 
resultados = model.train(
    data="dataset/data.yaml",
    epochs=50,
    imgsz=640,
    batch=8,
    name="detector_botellas_latas"
)

El método train() realiza el entrenamiento utilizando las imágenes y etiquetas proporcionadas.

8. Argumentos del método train()

Argumento Función Ejemplo
data Ruta del archivo de configuración. data.yaml
epochs Número de épocas de entrenamiento. 50, 100, 200
imgsz Tamaño de entrada de las imágenes. 640, 416, 320
batch Imágenes procesadas por lote. 8, 16, 32
name Nombre de la carpeta de resultados. mi_modelo
device Dispositivo de entrenamiento. cpu, 0
patience Épocas sin mejora antes de detener anticipadamente el entrenamiento. 20
workers Procesos para cargar datos. 4

9. ¿Dónde se guarda el modelo?

Al finalizar, Ultralytics genera una carpeta de resultados. Normalmente tendrá esta estructura: 

runs/
└── detect/
    └── detector_botellas_latas/
        └── weights/
            ├── best.pt
            └── last.pt
  • best.pt: mejores pesos obtenidos durante el entrenamiento.
  • last.pt: pesos del último ciclo de entrenamiento.
El archivo best.pt contiene el modelo personalizado que utilizaremos para reconocer nuestras botellas y latas.

10. Realizar una detección

Crear un archivo llamado detectar_01.py. 

from ultralytics import YOLO

# Cargar nuestro modelo entrenado
model = YOLO(
    "runs/detect/detector_botellas_latas/weights/best.pt"
)

# Detectar objetos en una imagen
resultados = model.predict(
    source="prueba.jpg",
    conf=0.40,
    save=True
)

print("Detección finalizada")

En este ejemplo, YOLO analiza la imagen prueba.jpg, identifica los objetos y guarda una copia con las detecciones.

11. Argumentos del método predict()

Argumento Descripción
source Imagen, carpeta, video, URL o cámara.
conf Confianza mínima para aceptar una detección. Ejemplo: 0.40.
iou Umbral de IoU para eliminar detecciones duplicadas.
imgsz Tamaño de procesamiento de imagen.
save Guardar imágenes con las detecciones.
show Mostrar visualmente los resultados.
device Dispositivo utilizado para realizar la predicción.
max_det Número máximo de detecciones por imagen.

12. Actividad práctica

  1. Entrenar el modelo con imágenes de botellas y latas.
  2. Realizar pruebas con fotografías diferentes.
  3. Modificar el valor de confianza conf.
  4. Comparar los resultados con diferentes valores.
Laboratorio 02

Crear y entrenar un modelo con objetos propios

En este laboratorio cada estudiante creará su propio conjunto de datos y entrenará un modelo para reconocer objetos elegidos por él.

1. Planteamiento

Se desarrollará un detector personalizado capaz de reconocer tres objetos diferentes.

Ejemplo de clases:

  • Destornillador.
  • Martillo.
  • Alicate.

El estudiante podrá sustituir estos objetos por cualquier otro conjunto de elementos que pueda fotografiar.

2. Recolección de imágenes

Fotografiar cada objeto desde diferentes perspectivas. Se recomienda comenzar con 100 imágenes por clase y aumentar la cantidad conforme se evalúen los resultados.

Las fotografías deben considerar:

  • Diferentes orientaciones del objeto.
  • Diferentes distancias de la cámara.
  • Variaciones de iluminación.
  • Diferentes fondos.
  • Objetos individuales y varios objetos en una misma imagen.
Las imágenes de entrenamiento y validación deben ser diferentes. No se deben utilizar fotografías casi idénticas en ambas carpetas, porque esto puede producir una evaluación engañosa.

3. Etiquetar las imágenes

Utilizar Roboflow para crear un nuevo proyecto de tipo Object Detection.

  1. Subir las fotografías.
  2. Crear las clases correspondientes.
  3. Dibujar un rectángulo alrededor de cada objeto.
  4. Asignar correctamente cada etiqueta.
  5. Verificar que no existan objetos sin etiquetar.
  6. Dividir el conjunto en entrenamiento, validación y prueba.
  7. Exportar en formato YOLO.

4. Verificar las clases

El archivo data.yaml debe contener las clases que queremos reconocer. 

path: ./herramientas

train: train/images
val: valid/images
test: test/images

names:
  0: destornillador
  1: martillo
  2: alicate
El orden de las clases es importante. Los identificadores de los archivos TXT deben coincidir con los definidos en el archivo YAML.

5. Entrenamiento del modelo personalizado

Crear un archivo llamado entrenamiento_02.py. 

# ==========================================
# LABORATORIO 02
# Entrenamiento de un detector personalizado
# ==========================================

from ultralytics import YOLO

# 1. Cargar modelo preentrenado
model = YOLO("yolo26n.pt")

# 2. Entrenar con nuestro conjunto de datos
resultados = model.train(
    data="herramientas/data.yaml",
    epochs=100,
    imgsz=640,
    batch=8,
    patience=25,
    name="detector_herramientas"
)

# 3. Mostrar finalización
print("Modelo personalizado entrenado")


# ==========================================
# 4. Cargar los mejores pesos
# ==========================================

modelo_entrenado = YOLO(
    "runs/detect/detector_herramientas/weights/best.pt"
)

# 5. Evaluar el modelo
metricas = modelo_entrenado.val()

print("Evaluación finalizada")

print("mAP50:", metricas.box.map50)
print("mAP50-95:", metricas.box.map)

6. Explicación de las nuevas instrucciones

Evaluar el modelo: val() 
metricas = modelo_entrenado.val()
Permite comprobar qué tan bien reconoce los objetos utilizando las imágenes reservadas para validación.

Algunos resultados importantes:

Métrica Significado
Precision Qué proporción de las detecciones realizadas fue correcta.
Recall Qué proporción de los objetos existentes logró detectar.
mAP50 Precisión media con un umbral IoU de 0.50.
mAP50-95 Promedio de precisión media en diferentes umbrales IoU.
Un resultado alto no garantiza que el modelo funcione correctamente en cualquier escenario. Es necesario realizar pruebas con fotografías que no haya utilizado durante el entrenamiento.

7. Realizar detecciones con el modelo propio

Crear un archivo llamado prueba_modelo.py. 

from ultralytics import YOLO

# Cargar modelo personalizado
model = YOLO(
    "runs/detect/detector_herramientas/weights/best.pt"
)

# Detectar herramientas
resultados = model.predict(
    source="herramienta_prueba.jpg",
    conf=0.50,
    imgsz=640,
    save=True
)

# Mostrar resultados de cada detección
for resultado in resultados:

    for caja in resultado.boxes:

        clase = int(caja.cls[0])
        confianza = float(caja.conf[0])

        nombre = resultado.names[clase]

        print("Objeto:", nombre)
        print("Confianza:", round(confianza, 2))

8. Comprender los resultados de detección

El método predict() devuelve una lista de resultados. Cada resultado contiene información de los objetos detectados en una imagen.

Elemento Función
resultado.boxes Contiene los rectángulos detectados.
caja.cls Identificador de la clase detectada.
caja.conf Valor de confianza de la detección.
caja.xyxy Coordenadas del rectángulo en píxeles.
resultado.names Diccionario con los nombres de las clases.
resultado.plot() Devuelve la imagen con las detecciones dibujadas.

9. Detección utilizando una cámara web

También podemos utilizar el modelo personalizado para detectar objetos en tiempo real. 

from ultralytics import YOLO

# Cargar modelo personalizado
model = YOLO(
    "runs/detect/detector_herramientas/weights/best.pt"
)

# Ejecutar detección con la cámara
model.predict(
    source=0,
    conf=0.50,
    show=True
)

El argumento source=0 indica que se utilizará la cámara predeterminada del equipo.

Para finalizar la ventana de detección, presionar la tecla ESC o cerrar la ventana.

10. Mejorar el modelo

Si el modelo no reconoce correctamente los objetos, se puede repetir el entrenamiento modificando algunos parámetros. 

model = YOLO("yolo26n.pt")

model.train(
    data="herramientas/data.yaml",
    epochs=150,
    imgsz=640,
    batch=8,
    patience=30,
    augment=True,
    name="detector_herramientas_v2"
)

Algunos aspectos que se pueden modificar:

  • Aumentar la cantidad de imágenes etiquetadas.
  • Corregir etiquetas incorrectas.
  • Agregar fotografías con diferentes condiciones.
  • Modificar la cantidad de épocas.
  • Probar diferentes tamaños de imagen.
  • Experimentar con aumentación de datos.
Referencia técnica

Principales métodos utilizados

Método Uso Ejemplo
YOLO() Cargar o crear un modelo. YOLO("yolo26n.pt")
train() Entrenar un modelo. model.train(data=...)
val() Evaluar el modelo. model.val()
predict() Detectar objetos. model.predict(source=...)
export() Exportar el modelo a otro formato. model.export(format="onnx")

Otros argumentos de entrenamiento

Argumento Descripción
pretrained Utilizar pesos preentrenados.
optimizer Optimizador: SGD, Adam o AdamW.
lr0 Tasa inicial de aprendizaje.
weight_decay Regularización de pesos.
mosaic Probabilidad de aplicar aumentación Mosaic.
flipud Probabilidad de volteo vertical.
fliplr Probabilidad de volteo horizontal.
degrees Grados de rotación aleatoria.
scale Factor de escalado aleatorio.
Estos son argumentos adicionales que se pueden experimentar. No es necesario utilizarlos todos en un mismo entrenamiento. Sus valores y disponibilidad dependen de la versión y tarea del modelo.
