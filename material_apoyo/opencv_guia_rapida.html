Guía rápida de OpenCV

Funciones frecuentes para leer, mostrar, guardar y transformar imágenes con Python. Cada ficha incluye el propósito, parámetros habituales y un ejemplo comentado.

InicioArchivos y ventanasPropiedades y píxelesColorTransformacionesAnálisisBordes y contornosVideo y cámara
Instalación: python -m pip install opencv-python numpy
Importación habitual: import cv2 y import numpy as np.
Consejo: comprueba que la imagen no sea None después de cv2.imread(). En OpenCV, las imágenes a color normalmente se leen en orden BGR, no RGB. Las ventanas de imshow() necesitan un entorno gráfico compatible.

Antes de comenzar

Convención de dimensiones: imagen.shape devuelve normalmente (alto, ancho, canales); en cambio, el tamaño de salida de cv2.resize() se escribe como (ancho, alto).

Coordenadas: el origen está en la esquina superior izquierda. Las columnas aumentan hacia la derecha y las filas hacia abajo. El recorte imagen[y1:y2, x1:x2] usa primero filas y luego columnas; el límite final no se incluye.

1. Archivos y ventanas

cv2.imread()

Carga una imagen del disco y devuelve una matriz NumPy.

cv2.imread(filename, flags=cv2.IMREAD_COLOR)
Parámetros

filename: ruta del archivo. flags: modo de lectura.

imagen = cv2.imread("foto.jpg")
gris = cv2.imread("foto.jpg", cv2.IMREAD_GRAYSCALE)
sin_cambios = cv2.imread("foto.png", cv2.IMREAD_UNCHANGED)

if imagen is None:
    print("No se pudo cargar la imagen")

Flags frecuentes: IMREAD_COLOR (color BGR), IMREAD_GRAYSCALE (gris), IMREAD_UNCHANGED (conserva canal alfa si existe).

cv2.imshow()

Muestra una imagen en una ventana.

cv2.imshow(winname, mat)
Parámetros

winname: título de ventana. mat: imagen a mostrar.

cv2.imshow("Imagen original", imagen)
cv2.waitKey(0)       # Espera una tecla
cv2.destroyAllWindows()

No omitas waitKey() en scripts tradicionales: permite procesar eventos de ventana.

cv2.imwrite()

Guarda una matriz como archivo de imagen.

cv2.imwrite(filename, img[, params])
correcto = cv2.imwrite("salida.png", imagen)
if correcto:
    print("Archivo guardado")
else:
    print("No se pudo guardar")

La extensión suele determinar el formato. La carpeta de destino debe existir y ser escribible.

cv2.waitKey() y cv2.destroyAllWindows()

Gestionan la interacción y el cierre de ventanas.

tecla = cv2.waitKey(0) & 0xFF
if tecla == 27:       # ESC
    cv2.destroyAllWindows()
elif tecla == ord("s"):
    cv2.imwrite("guardada.png", imagen)
    cv2.destroyAllWindows()

waitKey(0) espera indefinidamente; waitKey(30) espera aproximadamente 30 ms entre eventos.

2. Propiedades y píxeles

shape, size, dtype

Propiedades de la matriz de imagen, no funciones de OpenCV.

alto, ancho = imagen.shape[:2]
print("Dimensiones:", ancho, "x", alto)
print("Forma de matriz:", imagen.shape)
print("Cantidad de valores:", imagen.size)
print("Tipo de dato:", imagen.dtype)

Una imagen a color común tiene forma (alto, ancho, 3) y tipo uint8.

Acceder y modificar píxeles

Se utiliza el slicing de NumPy.

# Pixel en fila 50, columna 100 (B, G, R)
pixel = imagen[50, 100]
print(pixel)

# Cambiar ese píxel a rojo en BGR
imagen[50, 100] = [0, 0, 255]

# Recortar: filas y luego columnas
roi = imagen[50:200, 100:300]

Verifica que las coordenadas estén dentro de los límites de la imagen.

np.clip() para limitar intensidades

Útil al sumar o restar valores para ajustar el brillo.

import numpy as np

mas_clara = np.clip(
    imagen.astype(np.int16) + 35,
    0, 255
).astype(np.uint8)

mas_oscura = np.clip(
    imagen.astype(np.int16) - 35,
    0, 255
).astype(np.uint8)

Convertir temporalmente a un tipo con signo evita el desbordamiento al restar en matrices uint8.

3. Color y conversión de espacios

cv2.cvtColor()

Convierte una imagen de un espacio de color a otro.

cv2.cvtColor(src, code[, dst[, dstCn]])
gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
rgb = cv2.cvtColor(imagen, cv2.COLOR_BGR2RGB)
hsv = cv2.cvtColor(imagen, cv2.COLOR_BGR2HSV)

El código de conversión debe corresponder al formato real de la imagen de entrada.

RGB, BGR y HSV

Modelos de representación del color.

  • BGR: orden usado normalmente por OpenCV al leer color.
  • RGB: frecuente en otras bibliotecas de visualización.
  • HSV: tono, saturación y valor; útil para segmentar colores.
# Máscara de ejemplo para tonos rojos
hsv = cv2.cvtColor(imagen, cv2.COLOR_BGR2HSV)
inferior = np.array([0, 100, 80])
superior = np.array([10, 255, 255])
mascara = cv2.inRange(hsv, inferior, superior)

El rojo puede aparecer cerca de ambos extremos del tono HSV; para cubrirlo por completo suele combinarse más de una máscara.

cv2.split() y cv2.merge()

Separan o combinan los canales de una imagen.

azul, verde, rojo = cv2.split(imagen)
imagen_combinada = cv2.merge((azul, verde, rojo))

Los nombres siguen el orden de los canales de la matriz BGR.

4. Transformaciones de imagen

cv2.resize()

Cambia el tamaño de la imagen.

cv2.resize(src, dsize[, dst[, fx[, fy[, interpolation]]]])
# Tamaño exacto: (ancho, alto)
pequena = cv2.resize(
    imagen, (320, 240),
    interpolation=cv2.INTER_AREA
)

# Escala relativa
grande = cv2.resize(
    imagen, None, fx=1.5, fy=1.5,
    interpolation=cv2.INTER_CUBIC
)

INTER_AREA suele convenir al reducir; INTER_LINEAR es una opción general; INTER_CUBIC puede utilizarse al ampliar.

Brillo y contraste

Operaciones aritméticas sobre las intensidades.

# Brillo: suma una constante
brillo = cv2.convertScaleAbs(imagen, alpha=1.0, beta=35)

# Contraste y brillo:
# alpha controla escala; beta, desplazamiento
ajustada = cv2.convertScaleAbs(
    imagen, alpha=1.3, beta=10
)

alpha mayor que 1 aumenta la escala de intensidad; beta desplaza los valores. Los resultados se saturan al rango de salida.

cv2.normalize()

Normaliza los valores de una matriz a un rango determinado.

normalizada = cv2.normalize(
    imagen, None, 0, 255,
    cv2.NORM_MINMAX
)

La normalización min-max ajusta los valores mínimos y máximos. En imágenes a color, el resultado puede depender de cómo se aplica a la matriz completa.

cv2.flip()

Refleja una imagen.

horizontal = cv2.flip(imagen, 1)
vertical = cv2.flip(imagen, 0)
ambos = cv2.flip(imagen, -1)

Código 1: eje vertical (reflejo horizontal). Código 0: eje horizontal. Código -1: ambos ejes.

cv2.rotate()

Gira una imagen en ángulos predefinidos.

giro_90_horario = cv2.rotate(
    imagen, cv2.ROTATE_90_CLOCKWISE
)
giro_180 = cv2.rotate(
    imagen, cv2.ROTATE_180
)
giro_90_antihorario = cv2.rotate(
    imagen, cv2.ROTATE_90_COUNTERCLOCKWISE
)

cv2.getRotationMatrix2D() y cv2.warpAffine()

Permiten rotar alrededor de un punto.

alto, ancho = imagen.shape[:2]
centro = (ancho // 2, alto // 2)

matriz = cv2.getRotationMatrix2D(
    centro, 30, 1.0
)
rotada = cv2.warpAffine(
    imagen, matriz, (ancho, alto)
)

Parámetros principales: centro, ángulo en grados, escala y tamaño de salida en orden (ancho, alto).

5. Análisis básico de imágenes

cv2.calcHist()

Calcula el histograma de uno o varios canales.

cv2.calcHist(images, channels, mask, histSize, ranges)
gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
histograma = cv2.calcHist(
    [gris], [0], None, [256], [0, 256]
)

channels=[0] selecciona el primer canal de la imagen en gris; histSize=[256] usa 256 intervalos; ranges=[0, 256] define el rango.

cv2.threshold()

Convierte una imagen en función de un umbral de intensidad.

cv2.threshold(src, thresh, maxval, type)
gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
_, binaria = cv2.threshold(
    gris, 127, 255, cv2.THRESH_BINARY
)

Los píxeles por encima del umbral se convierten en el valor máximo; los demás, en cero. Requiere normalmente una imagen de un canal.

cv2.adaptiveThreshold()

Calcula umbrales locales, útil con iluminación desigual.

binaria = cv2.adaptiveThreshold(
    gris, 255,
    cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY,
    11, 2
)

Parámetros clave: valor máximo, método adaptativo, tipo de umbral, tamaño impar del vecindario y constante que se resta.

cv2.inRange()

Genera una máscara para valores dentro de un rango.

hsv = cv2.cvtColor(imagen, cv2.COLOR_BGR2HSV)
inferior = np.array([35, 60, 40])
superior = np.array([85, 255, 255])
mascara = cv2.inRange(hsv, inferior, superior)
resultado = cv2.bitwise_and(
    imagen, imagen, mask=mascara
)

Los límites deben adaptarse al color, la iluminación y la cámara.

Operaciones bitwise

Combinan imágenes o regiones mediante operaciones binarias.

union = cv2.bitwise_or(imagen_a, imagen_b)
interseccion = cv2.bitwise_and(imagen_a, imagen_b)
inversion = cv2.bitwise_not(imagen)
diferencia = cv2.bitwise_xor(imagen_a, imagen_b)

Para combinar imágenes, normalmente deben tener dimensiones y tipos compatibles.

6. Bordes, contornos y suavizado

cv2.GaussianBlur()

Suaviza la imagen y puede reducir ruido antes de detectar bordes.

suave = cv2.GaussianBlur(
    imagen, (5, 5), 0
)

El tamaño del kernel suele ser impar, por ejemplo (3,3) o (5,5). Sigma 0 permite que OpenCV lo calcule a partir del kernel.

cv2.Canny()

Detecta bordes a partir de cambios de intensidad.

cv2.Canny(image, threshold1, threshold2)
gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
bordes = cv2.Canny(gris, 100, 200)
cv2.imshow("Bordes", bordes)

Los dos umbrales controlan la detección por histéresis. Los valores óptimos dependen de la imagen.

cv2.findContours()

Busca contornos en una imagen binaria.

gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
_, binaria = cv2.threshold(
    gris, 127, 255, cv2.THRESH_BINARY
)
contornos, jerarquia = cv2.findContours(
    binaria, cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)

salida = imagen.copy()
cv2.drawContours(salida, contornos, -1, (0,255,0), 2)

RETR_EXTERNAL recupera contornos externos. CHAIN_APPROX_SIMPLE comprime puntos redundantes. El comportamiento de retorno puede variar en ejemplos antiguos de OpenCV.

cv2.rectangle() y cv2.putText()

Dibujan anotaciones sobre una imagen.

anotada = imagen.copy()
cv2.rectangle(
    anotada, (30, 40), (220, 180),
    (0, 255, 0), 2
)
cv2.putText(
    anotada, "Objeto",
    (30, 30), cv2.FONT_HERSHEY_SIMPLEX,
    0.8, (0, 255, 0), 2
)

Los colores de dibujo se especifican en BGR. Un grosor negativo en algunas funciones de dibujo rellena la figura.

cv2.circle() y cv2.line()

Dibujan círculos y líneas.

cv2.circle(imagen, (100, 100), 30, (255, 0, 0), 2)
cv2.line(imagen, (10, 10), (200, 120), (0, 255, 255), 3)

Los puntos usan coordenadas (x, y). Si no quieres modificar la original, dibuja sobre imagen.copy().

7. Video y cámara

cv2.VideoCapture()

Abre una cámara o un archivo de video.

captura = cv2.VideoCapture(0)  # Cámara predeterminada
# También: cv2.VideoCapture("video.mp4")

if not captura.isOpened():
    print("No se pudo abrir la cámara")
else:
    correcto, fotograma = captura.read()
    if correcto:
        cv2.imshow("Cámara", fotograma)

captura.release()
cv2.destroyAllWindows()

El índice 0 suele representar la cámara predeterminada; puede variar según el equipo.

Bucle básico de video

Lee y muestra fotogramas hasta pulsar ESC.

captura = cv2.VideoCapture(0)

while captura.isOpened():
    correcto, fotograma = captura.read()
    if not correcto:
        break

    cv2.imshow("Video en vivo", fotograma)
    if (cv2.waitKey(1) & 0xFF) == 27:
        break

captura.release()
cv2.destroyAllWindows()

Libera siempre el recurso de la cámara al terminar.

8. Plantilla mínima reutilizable

Una estructura segura para comenzar ejercicios de procesamiento de imágenes.

import cv2
import numpy as np

RUTA = "imagen.jpg"

imagen = cv2.imread(RUTA)

if imagen is None:
    print(f"No se pudo abrir: {RUTA}")
else:
    alto, ancho = imagen.shape[:2]
    print(f"Dimensiones: {ancho} x {alto}")

    gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)
    reducida = cv2.resize(
        imagen, (320, 240),
        interpolation=cv2.INTER_AREA
    )

    cv2.imshow("Original", imagen)
    cv2.imshow("Escala de grises", gris)
    cv2.imshow("Redimensionada", reducida)

    cv2.waitKey(0)
    cv2.destroyAllWindows()
