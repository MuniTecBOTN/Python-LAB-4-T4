1. Fundamentos del procesamiento de imágenes

¿Qué es una imagen digital?

Una imagen digital puede representarse como una matriz de píxeles. Cada píxel almacena uno o varios valores que describen su color. En una imagen a color habitual, cada píxel tiene tres canales.

  • Ancho: cantidad de píxeles horizontales.
  • Alto: cantidad de píxeles verticales.
  • Canales: componentes utilizados para representar el color.
import cv2

imagen = cv2.imread("frutas.jpg")

if imagen is None:
    raise FileNotFoundError("No se encontró la imagen")

print("Dimensiones:", imagen.shape)

cv2.imread() intenta cargar el archivo y devuelve una matriz de imagen. Si la ruta no existe o el archivo no se puede leer, suele devolver None. Por eso se comprueba el resultado antes de procesarlo.

Para una imagen a color convencional, imagen.shape suele tener la forma (alto, ancho, 3). El tercer valor representa los tres canales.

Importante: el orden de los valores de shape es alto, ancho y canales, no ancho, alto y canales.

¿Qué es BGR?

OpenCV utiliza habitualmente el orden BGR al cargar imágenes a color. Por ejemplo, el verde puro se representa con la tupla (0, 255, 0). El rojo puro sería (0, 0, 255) y el azul puro (255, 0, 0).

2. Conversión de BGR a HSV

Seleccionar colores directamente en BGR puede resultar poco intuitivo porque los tres canales representan intensidades de color. HSV separa el tono, la saturación y el valor, lo que facilita definir rangos aproximados de un color.

H — Hue / tono

Representa la familia de color, como rojo, verde o azul.

S — Saturation / saturación

Representa la intensidad o pureza del color. Valores bajos tienden a colores apagados o grises.

V — Value / valor

Representa la intensidad luminosa del color en el modelo HSV.

¿Por qué HSV?

Permite definir intervalos de tono y restringir saturación o luminosidad para excluir algunos píxeles no deseados.

hsv = cv2.cvtColor(
    imagen,
    cv2.COLOR_BGR2HSV
)

cv2.cvtColor() transforma la imagen de un espacio de color a otro. cv2.COLOR_BGR2HSV indica que la entrada está en BGR y se desea convertir a HSV. La variable hsv almacena la imagen transformada.

Precaución: en OpenCV, cuando HSV se representa con 8 bits, H suele ir de 0 a 179, mientras que S y V van de 0 a 255. Los rangos no son universales: deben probarse con las imágenes utilizadas.

3. Rangos de color y máscaras

Definir un intervalo

inferior = (35, 70, 50)
superior = (85, 255, 255)

mascara = cv2.inRange(
    hsv,
    inferior,
    superior
)

Las tuplas establecen los límites inferior y superior de los canales HSV. cv2.inRange() examina cada píxel y genera una máscara: los píxeles que están dentro de todos los intervalos quedan blancos (255); los que quedan fuera, negros (0).

Utilizar la máscara para extraer el color

resultado = cv2.bitwise_and(
    imagen,
    imagen,
    mask=mascara
)

La máscara indica qué píxeles conservar. Donde la máscara es blanca, se conserva el píxel original; donde es negra, el resultado queda negro. La operación no reconoce el objeto: solo aplica la selección definida por la máscara.

Cargar imagen→Convertir a HSV→Definir rango→Crear máscara→Extraer píxeles

¿Es obligatorio utilizar NumPy?

No siempre. En funciones como cv2.inRange() pueden utilizarse tuplas para especificar los límites. NumPy resulta especialmente útil cuando se realizan operaciones matemáticas con matrices o se desea seleccionar muchos píxeles simultáneamente.

4. Script 1 — Aislar un color rojo

Objetivo: conservar en la imagen los píxeles que corresponden aproximadamente al rojo y generar una máscara de selección.

¿Por qué se utilizan dos rangos?

El tono rojo se encuentra cerca de ambos extremos de la escala circular de H. Por eso un solo intervalo puede no capturar todos los rojos. Se crean dos máscaras y luego se combinan.

# Rango rojo cercano al inicio de H
inferior1 = (0, 100, 80)
superior1 = (10, 255, 255)

# Rango rojo cercano al final de H
inferior2 = (170, 100, 80)
superior2 = (179, 255, 255)

mascara1 = cv2.inRange(
    hsv, inferior1, superior1
)
mascara2 = cv2.inRange(
    hsv, inferior2, superior2
)

mascara = cv2.bitwise_or(
    mascara1, mascara2
)

resultado = cv2.bitwise_and(
    imagen, imagen, mask=mascara
)

La función `cv2.bitwise_or()`

Combina las máscaras de modo que un píxel queda seleccionado si aparece como blanco en cualquiera de ellas. Así se unen los dos intervalos rojos.

Visualizar y guardar

cv2.imshow("Original", imagen)
cv2.imshow("Mascara roja", mascara)
cv2.imshow("Resultado", resultado)

cv2.imwrite("resultado_rojo.jpg", resultado)

cv2.waitKey(0)
cv2.destroyAllWindows()
  • cv2.imshow() muestra una ventana con la imagen.
  • cv2.imwrite() intenta guardar el resultado en un archivo.
  • cv2.waitKey(0) espera hasta que se pulse una tecla.
  • cv2.destroyAllWindows() cierra las ventanas creadas por OpenCV.
Para comprobar: ¿qué sucedería si se aumenta el límite inferior de saturación? ¿Qué objetos rojos podrían dejar de detectarse?

5. Script 2 — Detectar varios colores

Objetivo: aplicar el mismo proceso a distintos rangos de color sin repetir todo el código manualmente.

Organizar los rangos en un diccionario

colores = {
    "verde": (
        (35, 70, 50),
        (85, 255, 255)
    ),
    "azul": (
        (90, 70, 50),
        (130, 255, 255)
    ),
    "amarillo": (
        (20, 100, 100),
        (35, 255, 255)
    )
}

En este diccionario, cada clave es el nombre del color y su valor contiene dos tuplas: los límites inferior y superior. Los valores son aproximados y deben ajustarse para la fotografía concreta.

Recorrer los colores con un ciclo

for nombre, (inferior, superior) in colores.items():
    mascara = cv2.inRange(
        hsv, inferior, superior
    )

    resultado = cv2.bitwise_and(
        imagen, imagen, mask=mascara
    )

    cv2.imshow("Mascara " + nombre, mascara)
    cv2.imshow("Objetos " + nombre, resultado)

    cv2.imwrite("mascara_" + nombre + ".jpg", mascara)
    cv2.imwrite("objetos_" + nombre + ".jpg", resultado)

cv2.waitKey(0)
cv2.destroyAllWindows()

colores.items() permite recorrer pares de clave y valor. En cada vuelta, nombre recibe el nombre del color y las variables inferior y superior reciben sus límites. El ciclo crea y guarda una máscara y un resultado para cada color.

Ventaja: si se agrega un nuevo color al diccionario, el mismo ciclo puede procesarlo sin duplicar las instrucciones de filtrado.

Preguntas de análisis

  • ¿Por qué conviene reutilizar el mismo código dentro de un ciclo?
  • ¿Qué sucede si dos rangos se superponen?
  • ¿Por qué una máscara puede seleccionar partes del fondo del mismo color?

6. Script 3 — Detectar regiones y dibujar rectángulos

Objetivo: pasar de una máscara de píxeles a regiones delimitadas que puedan contarse y anotarse.

Encontrar contornos

contornos, jerarquia = cv2.findContours(
    mascara,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)
  • mascara: imagen binaria que se analiza.
  • cv2.RETR_EXTERNAL: recupera los contornos externos.
  • cv2.CHAIN_APPROX_SIMPLE: comprime puntos redundantes de los contornos.
  • contornos: colección de contornos encontrados.
  • jerarquia: información sobre relaciones entre contornos; puede ser None si no hay contornos.

Un contorno describe el límite de una región blanca de la máscara. No determina por sí mismo si la región es una pelota, una fruta o cualquier otro objeto.

Filtrar por área y calcular el rectángulo

resultado = imagen.copy()
contador = 0

for contorno in contornos:
    area = cv2.contourArea(contorno)

    if area < 300:
        continue

    x, y, ancho, alto = cv2.boundingRect(contorno)
    contador += 1

    cv2.rectangle(
        resultado,
        (x, y),
        (x + ancho, y + alto),
        (0, 255, 0),
        2
    )

    cv2.putText(
        resultado,
        "Objeto " + str(contador),
        (x, max(y - 10, 20)),
        cv2.FONT_HERSHEY_SIMPLEX,
        0.6,
        (0, 255, 0),
        2
    )

cv2.contourArea() calcula el área aproximada de un contorno. La condición if area < 300 ignora regiones pequeñas, que podrían ser ruido. El valor 300 es ilustrativo y debe ajustarse según la resolución y el tamaño de los objetos.

cv2.boundingRect() devuelve la coordenada horizontal x, la vertical y, el ancho y el alto del rectángulo que encierra la región. cv2.rectangle() dibuja ese rectángulo y cv2.putText() añade una etiqueta.

Limitación: si dos objetos del mismo color se tocan, pueden formar una única región y recibir un solo rectángulo. La calidad de la detección depende de la máscara.

Terminar el programa

print("Regiones detectadas:", contador)
cv2.imshow("Mascara", mascara)
cv2.imshow("Objetos detectados", resultado)
cv2.waitKey(0)
cv2.destroyAllWindows()

7. Script 4 — Cambiar el color de una región

Objetivo: modificar solo los píxeles seleccionados por una máscara, conservando el resto de la imagen.

Crear una copia

resultado = imagen.copy()

.copy() crea una copia independiente de los datos de la imagen. De esta manera, se conserva la imagen original para comparar resultados o reutilizarla.

Seleccionar píxeles mediante una condición

resultado[mascara > 0] = [255, 0, 0]

Esta instrucción utiliza indexación booleana de NumPy. La expresión mascara > 0 crea una selección de posiciones donde la máscara es distinta de cero. En esas posiciones se asigna el color azul BGR [255, 0, 0].

NumPy no es necesario para todas las operaciones básicas de OpenCV, pero sí resulta muy práctico para seleccionar y modificar muchos píxeles con una sola instrucción.

¿Qué limitación tiene este método?

Todos los píxeles seleccionados reciben el mismo azul uniforme. Se pierden las variaciones de sombras y reflejos del objeto. Una alternativa más avanzada consiste en modificar el tono en HSV y conservar en lo posible la saturación y el valor originales.

Reto: permite que el usuario seleccione el color de origen y el de destino. Compara el resultado de asignar un color uniforme con una transformación del canal H.

8. Script 5 — Calcular el porcentaje de color

Objetivo: convertir una máscara en una medición numérica que permita comparar imágenes o regiones.

Contar los píxeles

total_pixeles = imagen.shape[0] * imagen.shape[1]

pixeles_verdes = cv2.countNonZero(mascara)

imagen.shape[0] corresponde al alto y imagen.shape[1] al ancho. Al multiplicarlos se obtiene el número total de píxeles. cv2.countNonZero() cuenta los píxeles de la máscara cuyo valor no es cero; en una máscara binaria, estos suelen ser los blancos.

Calcular el porcentaje

porcentaje = (
    pixeles_verdes / total_pixeles
) * 100

print("Porcentaje:", round(porcentaje, 2), "%")

Si la imagen tiene 100 000 píxeles y 15 000 cumplen el rango de color, el porcentaje es (15000 / 100000) * 100 = 15%.

Interpretación correcta: el resultado es el porcentaje de píxeles seleccionados por la máscara. No representa necesariamente el porcentaje de superficie física ocupado por un objeto; la perspectiva, el fondo, las sombras y los errores de segmentación influyen en la medida.

Mostrar el resultado en la imagen

resultado = imagen.copy()

cv2.putText(
    resultado,
    f"Color: {porcentaje:.2f}%",
    (20, 40),
    cv2.FONT_HERSHEY_SIMPLEX,
    1,
    (0, 255, 0),
    2
)

La f-string f"Color: {porcentaje:.2f}%" inserta el valor de la variable con dos cifras decimales. La posición (20, 40) corresponde al punto inicial del texto.

Ideas clave para recordar

  • El filtrado por color selecciona píxeles según rangos definidos; no identifica automáticamente la categoría semántica de un objeto.
  • La calidad de la máscara condiciona las etapas posteriores.
  • Los contornos permiten analizar regiones, pero regiones conectadas pueden representar varios objetos.
  • Los resultados deben evaluarse con distintas imágenes y condiciones de iluminación.
