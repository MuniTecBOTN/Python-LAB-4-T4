PROYECTO FINAL

Desarrolla con YOLO

Ocho propuestas de proyectos para aplicar visión por computadora utilizando Python, YOLO y procesamiento de imágenes en tiempo real.

Propuestas de proyectos

Selecciona una propuesta y desarrolla un sistema capaz de detectar, identificar, clasificar o contar objetos mediante inteligencia artificial.

PROYECTO 01

Detección de cascos de seguridad

Identificación de personas que utilizan o no casco de seguridad en zonas de construcción o áreas industriales.

YOLO OpenCV Python
PROYECTO 02

Detector de espacios de estacionamiento

Detección de vehículos para determinar qué espacios de un estacionamiento están ocupados y cuáles se encuentran disponibles.

YOLO OpenCV Detección de objetos
PROYECTO 03

Clasificador de residuos

Identificación y clasificación de residuos como plástico, papel, vidrio y metal para facilitar los procesos de reciclaje.

YOLO Clasificación Python
PROYECTO 04

Monitor de tráfico vehicular

Detección y conteo de automóviles, motocicletas, autobuses y camiones para analizar el flujo de tránsito.

YOLO Seguimiento OpenCV
PROYECTO 05

Inspección de productos en una banda transportadora

Identificación y conteo de productos mediante una cámara, detectando elementos diferentes a los esperados o posibles defectos visibles.

YOLO OpenCV Tiempo real
PROYECTO 06

Detector y clasificador de herramientas

Reconocimiento de herramientas como martillos, destornilladores, alicates y llaves, permitiendo identificar y contabilizar cada elemento.

YOLO Detección Python
PROYECTO 07

Sistema de detección de animales

Identificación de diferentes animales mediante una cámara, permitiendo reconocer especies, detectar su presencia y llevar un conteo.

YOLO OpenCV Clasificación
PROYECTO 08

Monitor de aforo de personas

Detección y conteo de personas que ingresan o salen de un establecimiento para controlar la cantidad de individuos presentes.

YOLO Seguimiento OpenCV

Consideraciones para el proyecto final

Cada proyecto debe implementar un modelo YOLO, utilizar imágenes o video como entrada y mostrar visualmente los resultados de las detecciones. Se recomienda utilizar una cámara web para demostrar el funcionamiento en tiempo real.
