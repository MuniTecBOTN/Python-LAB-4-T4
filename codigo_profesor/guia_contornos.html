1. Objetivos de aprendizaje

Al finalizar esta guía podrás:

  • Explicar qué es un contorno y por qué suele detectarse en una imagen binaria.
  • Recuperar contornos con cv2.findContours().
  • Calcular el área de cada región con cv2.contourArea().
  • Obtener la posición y las dimensiones de un rectángulo con cv2.boundingRect().
  • Combinar los métodos para ignorar regiones pequeñas y dibujar recuadros sobre los objetos.

2. Preparación: ¿qué es un contorno?

Un contorno es una secuencia de puntos que representa el límite de una región u objeto en una imagen. Puede describir la silueta de una moneda, una pieza, una mancha de color o cualquier forma que se haya separado del fondo.

Estos métodos no reconocen por sí solos si una forma es una moneda o una pieza. Analizan las regiones que se han separado previamente. Por eso, la preparación de la imagen es importante.

¿Por qué utilizar una imagen binaria?

Una imagen binaria suele representar los objetos de interés en blanco (255) y el fondo en negro (0). De esta manera se facilita el análisis de las regiones.

import cv2

imagen = cv2.imread("objetos.jpg")

if imagen is None:
    raise FileNotFoundError("No se encontró objetos.jpg")

gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)

# Los píxeles oscuros pasan a blanco; los claros, a negro.
_, binaria = cv2.threshold(
    gris, 127, 255, cv2.THRESH_BINARY_INV
)

cv2.imshow("Original", imagen)
cv2.imshow("Imagen binaria", binaria)
cv2.waitKey(0)
cv2.destroyAllWindows()

THRESH_BINARY_INV invierte el resultado del umbral: los píxeles por debajo del umbral quedan blancos y los superiores quedan negros. Si los objetos son claros sobre fondo oscuro, prueba cv2.THRESH_BINARY. El valor 127 es un ejemplo que puede requerir ajustes.

Importante: procura que los objetos de interés queden blancos sobre un fondo negro. Si hay ruido, sombras o dos objetos conectados, la detección puede producir contornos incorrectos o agrupar varias formas en una sola región.

3. cv2.findContours(): encontrar los límites

Propósito: examinar una imagen binaria y devolver los contornos de sus regiones. Cada contorno contiene coordenadas de puntos que siguen el borde de una región blanca.

Sintaxis habitual

contornos, jerarquia = cv2.findContours(
    binaria,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)
ArgumentoExplicación
binariaImagen en la que se buscan los contornos. Habitualmente es una imagen de un canal con objetos blancos y fondo negro.
cv2.RETR_EXTERNALRecupera únicamente los contornos externos. Es útil cuando no se necesita analizar los huecos interiores de las formas.
cv2.CHAIN_APPROX_SIMPLEReduce los puntos guardados al omitir puntos intermedios redundantes en segmentos rectos.

¿Qué devuelve?

  • contornos: una lista de contornos. Cada elemento contiene puntos de coordenadas. Si no se detecta ninguno, la lista estará vacía.
  • jerarquia: describe relaciones entre contornos: cuál es el siguiente, el anterior, el primer hijo y el contorno padre. Las relaciones inexistentes se indican con -1.

Con RETR_EXTERNAL, la jerarquía suele ser menos importante en ejercicios introductorios.

Ejemplo: contar y explorar los contornos

contornos, jerarquia = cv2.findContours(
    binaria,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)

print("Contornos detectados:", len(contornos))

for indice, contorno in enumerate(contornos):
    print("Contorno:", indice + 1)
    print("Puntos guardados:", len(contorno))

len(contornos) cuenta los contornos, pero no garantiza que coincida con la cantidad real de objetos físicos. Un objeto puede producir fragmentos por el ruido y varios objetos conectados pueden formar un solo contorno.

Visualizar los contornos

vista = imagen.copy()

cv2.drawContours(
    vista,
    contornos,
    -1,             # Dibujar todos
    (0, 255, 0),    # Verde en BGR
    2               # Grosor
)

cv2.imshow("Contornos", vista)
cv2.waitKey(0)
cv2.destroyAllWindows()

cv2.drawContours() sirve para dibujar los contornos detectados. El argumento -1 indica que se dibujen todos. La copia evita modificar la imagen original.

Idea clave: findContours() encuentra límites y entrega sus puntos. No calcula por sí solo el área ni dibuja un rectángulo delimitador.

4. cv2.contourArea(): calcular el área

Propósito: calcular el área encerrada por los puntos de un contorno. Se utiliza, por ejemplo, para descartar pequeñas regiones de ruido o seleccionar objetos según su tamaño aparente.

Sintaxis

area = cv2.contourArea(contorno)

El resultado se expresa en unidades de píxeles cuadrados. No equivale directamente a centímetros cuadrados ni a otra unidad física; para obtener una medida física se requiere calibrar la imagen y realizar una conversión apropiada.

Calcular el área de cada contorno

for indice, contorno in enumerate(contornos):
    area = cv2.contourArea(contorno)
    print(f"Contorno {indice + 1}: {area:.2f} píxeles²")

enumerate() permite recorrer la lista y obtener el índice junto con el contorno. El formato :.2f muestra dos decimales.

Filtrar regiones pequeñas

area_minima = 500

for contorno in contornos:
    area = cv2.contourArea(contorno)

    if area > area_minima:
        print("Región aceptada:", area)
    else:
        print("Región descartada:", area)

El código acepta solo las regiones con área superior a 500 píxeles cuadrados. El umbral es ilustrativo: depende de la resolución, el tamaño de los objetos y la distancia de la cámara.

Área del contorno frente al área del rectángulo

Una forma circular o irregular no llena por completo el rectángulo que la contiene. Por eso, cv2.contourArea(contorno) normalmente no equivale a ancho * alto. El primero mide el área de la forma delimitada; el segundo mide el rectángulo envolvente.

Precaución: el área depende de la máscara binaria. Si se incluye sombra o ruido dentro de la región blanca, el cálculo puede no representar únicamente el objeto deseado.

5. cv2.boundingRect(): obtener el rectángulo delimitador

Propósito: calcular el rectángulo más pequeño alineado con los ejes de la imagen que contiene todos los puntos del contorno.

Sintaxis

x, y, ancho, alto = cv2.boundingRect(contorno)
ValorSignificado
xCoordenada horizontal del borde izquierdo.
yCoordenada vertical del borde superior.
anchoAncho del rectángulo, en píxeles.
altoAlto del rectángulo, en píxeles.

El origen (0, 0) se encuentra en la esquina superior izquierda. x aumenta hacia la derecha y y aumenta hacia abajo.

Dibujar el rectángulo

x, y, ancho, alto = cv2.boundingRect(contorno)

esquina_superior_izquierda = (x, y)
esquina_inferior_derecha = (x + ancho, y + alto)

cv2.rectangle(
    imagen,
    esquina_superior_izquierda,
    esquina_inferior_derecha,
    (0, 255, 0),  # Verde en BGR
    2              # Grosor
)

boundingRect() solo calcula los valores. La función cv2.rectangle() dibuja el recuadro utilizando las coordenadas de las esquinas.

Consultar dimensiones

print("Posición:", x, y)
print("Ancho:", ancho)
print("Alto:", alto)
print("Área del rectángulo:", ancho * alto)

ancho * alto representa el área rectangular que envuelve el contorno, no necesariamente el área real de la forma.

Idea clave: el método convierte una colección de puntos en cuatro valores fáciles de usar: posición horizontal, posición vertical, ancho y alto.

6. Programa integrado: detectar, filtrar y localizar

Este programa combina los tres métodos. Está planteado para una imagen con objetos oscuros sobre un fondo claro. La máscara se invierte para intentar dejar los objetos en blanco y el fondo en negro.

1. DetectarfindContours()
Encuentra los límites.
2. FiltrarcontourArea()
Ignora regiones pequeñas.
3. LocalizarboundingRect()
Calcula el rectángulo delimitador.
import cv2

# 1. Cargar la imagen
imagen = cv2.imread("objetos.jpg")

if imagen is None:
    raise FileNotFoundError("No se encontró objetos.jpg")

# 2. Convertir a escala de grises
gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)

# 3. Crear una máscara binaria
_, binaria = cv2.threshold(
    gris, 127, 255, cv2.THRESH_BINARY_INV
)

# 4. Encontrar los contornos externos
contornos, jerarquia = cv2.findContours(
    binaria,
    cv2.RETR_EXTERNAL,
    cv2.CHAIN_APPROX_SIMPLE
)

print("Contornos encontrados:", len(contornos))

# Dibujar sobre una copia de la imagen
resultado = imagen.copy()
area_minima = 500

# 5. Procesar cada contorno
for numero, contorno in enumerate(contornos, start=1):

    # Calcular el área
    area = cv2.contourArea(contorno)

    # Ignorar las regiones demasiado pequeñas
    if area <= area_minima:
        continue

    # Obtener posición y dimensiones
    x, y, ancho, alto = cv2.boundingRect(contorno)

    # Dibujar el rectángulo
    cv2.rectangle(
        resultado,
        (x, y),
        (x + ancho, y + alto),
        (0, 255, 0),
        2
    )

    # Escribir el área sobre el objeto
    texto = f"Area: {int(area)}"
    posicion_texto = (x, max(y - 10, 20))

    cv2.putText(
        resultado,
        texto,
        posicion_texto,
        cv2.FONT_HERSHEY_SIMPLEX,
        0.5,
        (0, 0, 255),
        2
    )

    print(
        f"Contorno {numero}: area={area:.1f}, "
        f"x={x}, y={y}, ancho={ancho}, alto={alto}"
    )

# 6. Mostrar resultados
cv2.imshow("Imagen binaria", binaria)
cv2.imshow("Objetos detectados", resultado)
cv2.waitKey(0)
cv2.destroyAllWindows()

Explicación por etapas

  1. Cargar y validar: imread() lee el archivo. Si la ruta no es válida, devuelve None; por eso se comprueba antes de procesar.
  2. Preparar: la conversión a gris y la umbralización producen la imagen binaria.
  3. Detectar: findContours() devuelve los límites de las regiones blancas.
  4. Medir: contourArea() calcula el área de cada contorno.
  5. Filtrar: continue salta el resto del ciclo cuando el área no supera el mínimo.
  6. Localizar: boundingRect() obtiene coordenadas y dimensiones del contorno aceptado.
  7. Mostrar: rectangle() dibuja el recuadro y putText() agrega la medida.
Si los resultados son incorrectos: inspecciona primero la ventana «Imagen binaria». Si los objetos no están bien separados del fondo, el problema está en la segmentación. Ajusta el umbral o utiliza otra técnica antes de modificar el análisis de contornos.

7. Errores frecuentes

ProblemaCausa posibleQué revisar
No aparecen contornos.La máscara no tiene regiones blancas útiles.Mostrar la máscara y revisar el umbral.
La imagen completa parece un solo objeto.El fondo se convirtió en blanco.Probar THRESH_BINARY o THRESH_BINARY_INV.
Hay demasiados contornos.Ruido, reflejos o pequeñas regiones aisladas.Mejorar la máscara y filtrar por área.
Dos objetos reciben un solo recuadro.Las regiones blancas se tocan o están conectadas.Mejorar la segmentación para separarlas.
El área no coincide con ancho × alto.Son mediciones diferentes.Distinguir el área del contorno del área rectangular.
El recuadro aparece desplazado.Las coordenadas pertenecen a otra escala o a una imagen recortada.Usar la misma imagen de referencia o transformar las coordenadas.

8. Práctica para el estudiante

Objetivo: detectar regiones en una fotografía, descartar las pequeñas y dibujar rectángulos alrededor de las aceptadas.

  1. Guarda como objetos.jpg una fotografía con objetos separados sobre un fondo uniforme.
  2. Ejecuta el programa integrado y observa la imagen binaria.
  3. Cambia area_minima a 100, 1000 y 3000. Compara cuántas regiones se dibujan.
  4. Imprime ancho, alto y ancho * alto. Compáralos con contourArea(contorno).
  5. Prueba una imagen en la que dos objetos se toquen y describe el resultado.

Preguntas de comprobación

1. ¿Qué devuelve findContours()?

Una lista de contornos y una estructura jerárquica que describe sus relaciones, según el modo de recuperación elegido.

2. ¿Qué sucede si aumenta el área mínima?

Se descartan más regiones pequeñas. Si el valor es demasiado alto, también pueden desaparecer objetos que sí interesan.

3. ¿boundingRect() dibuja el recuadro?

No. Calcula las coordenadas y dimensiones. Para dibujarlo se utiliza, por ejemplo, cv2.rectangle().

4. ¿La cantidad de contornos siempre es igual a la cantidad de objetos reales?

No. Depende de la máscara, del ruido, de los huecos y de si las regiones están separadas o conectadas.

5. ¿El área del contorno equivale a ancho por alto?

No. Una es el área de la forma; la otra es el área del rectángulo que la contiene.
