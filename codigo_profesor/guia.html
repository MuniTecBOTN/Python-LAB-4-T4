Manipulación y procesamiento de imágenes con OpenCV

Aprende a recortar, redimensionar, rotar, anotar y procesar imágenes mediante Python. Esta guía incluye cinco ejemplos prácticos con explicaciones, actividades y un proyecto integrador.

Duración sugerida: 2 horas y 30 minutos.

1. Introducción a la clase

Una imagen digital puede representarse como una matriz de píxeles. Cada píxel contiene información que permite representar colores o niveles de intensidad. OpenCV proporciona herramientas para acceder a esta información y transformarla mediante operaciones matemáticas.

Objetivo general Aplicar operaciones básicas de manipulación y procesamiento de imágenes con Python y OpenCV, comprendiendo los parámetros de las funciones y los resultados obtenidos.

Requisitos previos

  • Conocimientos básicos de Python.
  • Variables, condicionales e instrucciones de entrada y salida.
  • Uso básico de matrices o arreglos.
  • Un editor de código y Python instalado.

2. Ejemplo 1: Recortar una región de interés (ROI)

20 minutos NumPy Matrices Coordenadas
Objetivo: seleccionar una parte específica de una imagen para analizarla de forma independiente.

¿Qué es una región de interés?

Una región de interés, conocida como ROI por sus siglas en inglés, es una sección de una imagen que se selecciona para observarla o procesarla por separado.

Por ejemplo, si tenemos una fotografía que contiene varias frutas, podríamos seleccionar únicamente la zona donde aparece una manzana. Para hacerlo, no es necesario crear una imagen nueva desde cero: podemos seleccionar un rango de filas y columnas de la matriz original.

Código completo

import cv2

imagen = cv2.imread("fruta.jpg")

if imagen is None:
    raise FileNotFoundError("No se encontró fruta.jpg")

print("Dimensiones:", imagen.shape)

# Seleccionar una región de la imagen
recorte = imagen[100:300, 150:350]

cv2.imshow("Imagen original", imagen)
cv2.imshow("Region recortada", recorte)

cv2.waitKey(0)
cv2.destroyAllWindows()

Explicación paso a paso

1. Cargar la imagen cv2.imread() lee el archivo y lo convierte en una matriz que puede manipularse desde Python.
2. Validar la carga La condición imagen is None detecta si el archivo no pudo abrirse.
3. Consultar dimensiones imagen.shape permite conocer el alto, el ancho y, en imágenes a color, el número de canales.
4. Seleccionar la región Los rangos de filas y columnas definen qué parte de la imagen se conservará en el recorte.

¿Cómo funciona el recorte?

recorte = imagen[100:300, 150:350]

La estructura es la siguiente:

imagen[filas_inicio:filas_final, columnas_inicio:columnas_final]
Expresión Interpretación
100:300 Selecciona filas desde la 100 hasta la 299.
150:350 Selecciona columnas desde la 150 hasta la 349.

Python no incluye el límite final del rango. Por eso, el primer rango contiene 200 filas y el segundo contiene 200 columnas, siempre que la imagen tenga dimensiones suficientes.

Visualizar las imágenes

cv2.imshow() abre una ventana para mostrar la matriz como imagen. Podemos crear una ventana para la imagen original y otra para el recorte.

  • cv2.waitKey(0) espera hasta que se pulse una tecla.
  • cv2.destroyAllWindows() cierra las ventanas abiertas.
Problema frecuente: si las coordenadas superan las dimensiones de la imagen, el recorte puede ser menor de lo esperado. Consulta imagen.shape antes de seleccionar la región.

Actividad práctica

  1. Prueba diferentes valores para las filas y columnas.
  2. Genera dos recortes diferentes de la misma fotografía.
  3. Imprime las dimensiones de cada recorte.
  4. Explica cómo cambian los resultados al modificar las coordenadas.

3. Ejemplo 2: Redimensionar y rotar imágenes

20 minutos Dimensiones Escalado Rotación
Objetivo: modificar las dimensiones y la orientación de una imagen sin perder el control de su proporción.

¿Por qué redimensionar imágenes?

Las fotografías pueden contener millones de píxeles. Reducir sus dimensiones facilita su visualización y puede disminuir el tiempo requerido por operaciones posteriores.

Sin embargo, si cambiamos el ancho y el alto de manera independiente, podemos deformar los objetos. Para evitarlo, debemos conservar la relación de aspecto de la imagen.

Código completo

import cv2

imagen = cv2.imread("paisaje.jpg")

if imagen is None:
    raise FileNotFoundError("No se encontró paisaje.jpg")

alto, ancho = imagen.shape[:2]

# Reducir las dimensiones al 50 %
reducida = cv2.resize(
    imagen,
    (ancho // 2, alto // 2)
)

# Rotar 90 grados en sentido horario
rotada = cv2.rotate(
    imagen,
    cv2.ROTATE_90_CLOCKWISE
)

cv2.imshow("Original", imagen)
cv2.imshow("Reducida", reducida)
cv2.imshow("Rotada", rotada)

cv2.waitKey(0)
cv2.destroyAllWindows()

Comprender las dimensiones

En una imagen de OpenCV, imagen.shape suele devolver una estructura como esta: 

(600, 800, 3)
  • 600: alto en píxeles.
  • 800: ancho en píxeles.
  • 3: canales de color.

Por eso se utiliza imagen.shape[:2] para obtener únicamente el alto y el ancho.

¿Cómo funciona resize()?

cv2.resize(imagen, (nuevo_ancho, nuevo_alto))

Aunque shape presenta primero el alto y después el ancho, la función resize() recibe las dimensiones en el orden ancho y alto.

El operador // realiza una división entera. Al dividir ambas dimensiones entre dos, obtenemos una imagen con aproximadamente una cuarta parte del número original de píxeles.

Conservar la proporción con un ancho específico

Supongamos que queremos una imagen de 800 píxeles de ancho. Podemos calcular el alto proporcional utilizando la siguiente fórmula: 

nuevo_ancho = 800
nuevo_alto = int(alto * nuevo_ancho / ancho)

redimensionada = cv2.resize(
    imagen,
    (nuevo_ancho, nuevo_alto)
)

El cálculo conserva la proporción entre ancho y alto. La función int() convierte el resultado a un número entero de píxeles.

Rotar una imagen

OpenCV incluye tres rotaciones predefinidas:

ConstanteResultado
cv2.ROTATE_90_CLOCKWISE 90 grados en sentido horario.
cv2.ROTATE_180 180 grados.
cv2.ROTATE_90_COUNTERCLOCKWISE 90 grados en sentido antihorario.
Diferencia importante: recortar significa seleccionar una parte de la imagen. Redimensionar significa cambiar las dimensiones de la imagen completa.

Actividad práctica

  1. Redimensiona una imagen al 25 %, 50 % y 100 %.
  2. Genera una versión de 800 píxeles de ancho conservando la proporción.
  3. Prueba las tres rotaciones.
  4. Imprime las dimensiones de cada resultado.

4. Ejemplo 3: Dibujar figuras y agregar texto

25 minutos Anotaciones Colores BGR Coordenadas
Objetivo: añadir elementos gráficos sobre una imagen para marcar regiones, objetos o información relevante.

Aplicaciones de las anotaciones

Las anotaciones se utilizan para señalar zonas de interés y presentar resultados visuales. Por ejemplo, un programa de detección de objetos puede dibujar rectángulos alrededor de vehículos y colocar una etiqueta con la clase detectada.

Código completo

import cv2

imagen = cv2.imread("objetos.jpg")

if imagen is None:
    raise FileNotFoundError("No se encontró objetos.jpg")

# Crear una copia para conservar la imagen original
anotada = imagen.copy()

# Dibujar un rectángulo verde
cv2.rectangle(
    anotada, (50, 50), (250, 200),
    (0, 255, 0), 3
)

# Dibujar un círculo azul
cv2.circle(
    anotada, (350, 150), 50,
    (255, 0, 0), 3
)

# Agregar texto rojo
cv2.putText(
    anotada,
    "Objeto marcado",
    (50, 35),
    cv2.FONT_HERSHEY_SIMPLEX,
    0.8,
    (0, 0, 255),
    2
)

cv2.imshow("Original", imagen)
cv2.imshow("Imagen anotada", anotada)

cv2.waitKey(0)
cv2.destroyAllWindows()

Función rectangle()

cv2.rectangle(imagen, punto_inicial, punto_final, color, grosor)

El primer punto representa una esquina del rectángulo y el segundo la esquina opuesta. El color se indica mediante tres valores y el grosor determina cuántos píxeles tendrá el contorno.

Función circle()

cv2.circle(imagen, centro, radio, color, grosor)

El centro se define mediante coordenadas horizontales y verticales. El radio determina el tamaño del círculo. Un radio mayor produce una circunferencia más grande.

Función putText()

cv2.putText(
    imagen,
    "Texto",
    (50, 35),
    cv2.FONT_HERSHEY_SIMPLEX,
    0.8,
    (0, 0, 255),
    2
)

Sus argumentos principales son:

  • La imagen sobre la que se dibujará.
  • El texto que se mostrará.
  • La posición inicial del texto.
  • La fuente tipográfica.
  • El tamaño del texto.
  • El color en formato BGR.
  • El grosor de los caracteres.

El sistema de color BGR

OpenCV utiliza normalmente el orden BGR para representar los canales de color. Esto significa que el primer valor corresponde al azul, el segundo al verde y el tercero al rojo.

ColorValor BGR
Azul(255, 0, 0)
Verde(0, 255, 0)
Rojo(0, 0, 255)
Blanco(255, 255, 255)
Negro(0, 0, 0)
Buenas prácticas: las funciones de dibujo modifican la matriz que reciben. Si deseas conservar la imagen original, utiliza imagen.copy() y realiza las anotaciones sobre la copia.

Actividad práctica

  1. Dibuja tres rectángulos con colores diferentes.
  2. Agrega dos círculos en posiciones distintas.
  3. Escribe etiquetas que identifiquen los objetos.
  4. Guarda el resultado utilizando cv2.imwrite().
cv2.imwrite("imagen_anotada.jpg", anotada)

5. Ejemplo 4: Aplicar filtros y detectar bordes

35 minutos Escala de grises Desenfoque Canny
Objetivo: comprender cómo las transformaciones de imágenes permiten resaltar características y reducir información que no es necesaria para determinadas tareas.

¿Qué es el procesamiento de imágenes?

El procesamiento de imágenes consiste en aplicar operaciones a sus píxeles para modificar o resaltar información. En este ejemplo se construye una secuencia de tres etapas: conversión a escala de grises, suavizado y detección de bordes.

Código completo

import cv2

imagen = cv2.imread("edificio.jpg")

if imagen is None:
    raise FileNotFoundError("No se encontró edificio.jpg")

# Etapa 1: convertir a escala de grises
gris = cv2.cvtColor(
    imagen,
    cv2.COLOR_BGR2GRAY
)

# Etapa 2: reducir pequeñas variaciones y ruido
desenfocada = cv2.GaussianBlur(
    gris,
    (5, 5),
    0
)

# Etapa 3: detectar bordes
bordes = cv2.Canny(
    desenfocada,
    50,
    150
)

cv2.imshow("Imagen original", imagen)
cv2.imshow("Escala de grises", gris)
cv2.imshow("Imagen desenfocada", desenfocada)
cv2.imshow("Bordes detectados", bordes)

cv2.waitKey(0)
cv2.destroyAllWindows()

Etapa 1. Conversión a escala de grises

gris = cv2.cvtColor(imagen, cv2.COLOR_BGR2GRAY)

Una imagen a color suele contener tres canales. Al convertirla a escala de grises, se obtiene una representación de un solo canal que expresa la intensidad de cada píxel.

Esta transformación es útil cuando el color no es esencial para la operación que se desea realizar, como sucede en muchos métodos de detección de bordes.

Etapa 2. Desenfoque gaussiano

desenfocada = cv2.GaussianBlur(gris, (5, 5), 0)

El desenfoque gaussiano suaviza pequeñas variaciones de intensidad entre píxeles vecinos. Para hacerlo, combina los valores de una región alrededor de cada píxel mediante una ponderación gaussiana.

  • (5, 5) define un núcleo de cinco por cinco píxeles.
  • El valor 0 permite que OpenCV calcule automáticamente la desviación estándar correspondiente.

El suavizado puede reducir el efecto del ruido que, de otra manera, podría producir bordes no deseados.

Etapa 3. Detección de bordes con Canny

bordes = cv2.Canny(desenfocada, 50, 150)

Canny es un algoritmo de detección de bordes. Busca cambios significativos en la intensidad de los píxeles y produce una imagen donde los bordes detectados suelen aparecer en blanco sobre un fondo negro.

Los dos últimos argumentos son umbrales:

  • El umbral inferior ayuda a decidir qué gradientes débiles pueden conservarse cuando están conectados con bordes fuertes.
  • El umbral superior determina cuáles gradientes se consideran suficientemente fuertes para iniciar un borde.
Importante: detectar bordes no significa reconocer objetos. Canny puede resaltar los límites de una figura, pero no determina por sí solo si esa figura es una persona, un automóvil o un edificio.

Comparar distintos umbrales

bordes_1 = cv2.Canny(desenfocada, 30, 100)
bordes_2 = cv2.Canny(desenfocada, 50, 150)
bordes_3 = cv2.Canny(desenfocada, 100, 200)

cv2.imshow("Canny 30-100", bordes_1)
cv2.imshow("Canny 50-150", bordes_2)
cv2.imshow("Canny 100-200", bordes_3)

Al modificar los umbrales se modifica la cantidad y la continuidad de los bordes detectados. Los umbrales bajos pueden conservar más detalles, incluidos algunos debidos al ruido. Los umbrales altos pueden eliminar detalles débiles.

Actividad práctica

  1. Compara la imagen original con la versión en escala de grises.
  2. Observa las diferencias entre la imagen original y la desenfocada.
  3. Prueba tres parejas de umbrales para Canny.
  4. Guarda la imagen final con cv2.imwrite("bordes.png", bordes).
  5. Explica qué detalles se conservan y cuáles desaparecen.

6. Ejemplo 5: Mini proyecto, analizador de imágenes

40 minutos Integración Validación Proyecto práctico
Objetivo: integrar las operaciones anteriores en un programa que cargue una imagen, informe sus propiedades y muestre diferentes versiones procesadas.

Descripción del proyecto

El programa solicita al usuario la ruta de una imagen. Si puede cargarla, presenta sus dimensiones y el número de canales. Luego genera una versión en escala de grises, aplica un desenfoque y detecta los bordes. Finalmente, muestra todos los resultados.

Código completo

import cv2

# Solicitar la ruta del archivo
ruta = input("Ingrese la ruta de la imagen: ")

# Cargar la imagen
imagen = cv2.imread(ruta)

if imagen is None:
    print("Error: no se pudo cargar la imagen.")

else:
    # Consultar dimensiones
    alto, ancho = imagen.shape[:2]

    # Consultar el número de canales
    if len(imagen.shape) == 3:
        canales = imagen.shape[2]
    else:
        canales = 1

    print("Ancho:", ancho, "pixeles")
    print("Alto:", alto, "pixeles")
    print("Canales:", canales)

    # Convertir a escala de grises
    gris = cv2.cvtColor(
        imagen,
        cv2.COLOR_BGR2GRAY
    )

    # Aplicar desenfoque
    desenfocada = cv2.GaussianBlur(
        gris,
        (5, 5),
        0
    )

    # Detectar bordes
    bordes = cv2.Canny(
        desenfocada,
        50,
        150
    )

    # Mostrar los resultados
    cv2.imshow("Original", imagen)
    cv2.imshow("Escala de grises", gris)
    cv2.imshow("Desenfoque", desenfocada)
    cv2.imshow("Bordes", bordes)

    cv2.waitKey(0)
    cv2.destroyAllWindows()

Explicación del programa

Entrada de datos input() permite indicar la ruta de una imagen sin tener que modificar el código.
Validación La condición imagen is None evita que el programa intente procesar un archivo que no se pudo abrir.
Inspección shape proporciona el alto, el ancho y los canales de la matriz.
Procesamiento Se ejecutan varias operaciones en secuencia para obtener representaciones distintas de la misma imagen.

Retos adicionales

  1. Redimensionamiento: genera una imagen reducida al 50 % y muéstrala en una ventana adicional.
  2. Guardado: guarda el resultado de Canny con cv2.imwrite().
  3. Recorte: selecciona una región de interés y muestra sus dimensiones.
  4. Anotaciones: dibuja un rectángulo y coloca una etiqueta sobre la imagen.
  5. Parámetros: solicita al usuario los dos umbrales de Canny mediante input().
Criterios de logro: el programa debe manejar rutas inválidas, mostrar las dimensiones correctamente y producir las transformaciones solicitadas.
